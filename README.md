# ImpactSG Electronics Marketplace

A public second-hand electronics marketplace demo for people who want to browse, search, and compare listings without an account.

## Tech stack

Next.js (App Router), TypeScript, Tailwind CSS, JSON seed data, and an OpenAI-compatible CognitioLabs gateway.

## Run locally

Install Node.js 18.18+ and, from the project directory, install dependencies:

```powershell
npm install
```

Set the required environment variable name locally: `CLASSGW_KEY`.

```powershell
npm run dev
```

Open `http://localhost:3000`.

Live demo: [add deployment URL](https://example.com)

See `/notes` in the running app for full product details.
